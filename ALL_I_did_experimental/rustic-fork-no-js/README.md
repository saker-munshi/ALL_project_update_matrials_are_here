# Rustic Fork — No-JS Connected Version

This version keeps the Kitchen Display design but splits it into separate HTML pages.
Each page has its own CSS file. Navigation uses ordinary `<a href="...">` links only.

Pages:
- chef.html
- orders.html
- recipes.html
- chat.html
- time.html

No JavaScript file is required.

Note: because JavaScript is intentionally removed, search/filter controls, live clocks,
dynamic order state, and interactive chat submission are static visual controls rather
than live application features. The page-to-page navigation works without JavaScript.
